# Architecture

Este diretório contém a representação arquitetural visual oficial do Agent Lab Pascoal.

- `AGENT_LAB_ARCHITECTURE_MAP.md` — contrato, hierarquia de autoridade e protocolo de atualização do mapa;
- `agent_lab_architecture_graph_complete_v1_v2.html` — visualização interativa standalone e completa, cobrindo V1 fundacional e V2 atual.

O grafo é complementar ao `docs/PROJECT_COMPASS.md`. Ele interpreta o estado integrado do projeto, mas não cria contratos por desenho. Em caso de divergência, verificar código/testes, SPECs e `PROJECT_COMPASS`, e corrigir a projeção visual.

Pressões arquiteturais podem aparecer no grafo apenas quando estiverem marcadas explicitamente como **não implementadas**.
