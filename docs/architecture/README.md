# Architecture

Este diretório contém a representação arquitetural visual oficial do Agent Lab Pascoal.

- `AGENT_LAB_ARCHITECTURE_MAP.md` — contrato e regras de governança do mapa arquitetural;
- `agent_lab_architecture_graph_v2.html` — visualização interativa;
- `agent_lab_architecture_graph_v2_data.js` — dados versionados da visualização.

O grafo é complementar ao `docs/PROJECT_COMPASS.md`. Ele interpreta o estado integrado do projeto, mas não cria contratos por desenho. Em caso de divergência, verificar código/testes, SPECs e `PROJECT_COMPASS`, e corrigir a projeção visual.
